ЧТО ИЗВЕСТНО ТОЧНО
1. Консоль: та же игра с DXVK/NVK играется часами (гонки проходились, журналы в ветке `cloud/nfsu-vulkan-black`, `console/`).
2. Стенд, Eden 0001–0030: картинка есть (заставка/фон меню с машиной, HUD DXVK), ~13–27 fps на llvmpipe.
3. Через 30–45 с после первого кадра счётчик кадров рантайма (`[PROGRESS] … frames=`) встаёт навсегда: 1444 при 4 CPU (на видео с машиной), 1604 при 12 CPU (на чёрном кадре между заставками). Место в игре разное, время примерно одно. Нажатия A не помогают, Eden жив, ошибок «not implemented» в журнале Eden нет.
4. Стеки в момент остановки (`[STALL] … where the threads are standing`, расшифровка в `stall-symbols.txt`): 16 потоков сервера Wine ждут запросов; 8 потоков Wine в `NtWaitForAlertByThreadId` → `horizon_futex_wait` → `svcWaitForAddress`; 3 в `NtWaitForSingleObject/MultipleObjects` → `server_wait`; 2 в `NtDelayExecution`; `presenter_thread` композитора; главный поток игры (tid 4) — в переведённом x86-коде FEX, не в системном вызове (адрес JIT 0x28f08294).
5. Прошлые облака отмечали: Eden не сигналит fence, запрошенный при kickoff из libnx (`nvFenceWait` ждёт таймаут); гонку событий nvhost-ctrl исправил 0024 (у облака 0023).

ЗАДАЧА
