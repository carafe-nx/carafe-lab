- Патч 0001 пишет `Method … on subchannel N with no engine bound` и пропускает такие методы. Патч 0003 при AllocObjCtx класса 3D сам привязывает подканал 0 к 3D-движку, как nvgpu: Mesa на Switch на это полагается.

ЧТО ИЗВЕСТНО ТОЧНО
1. Консоль: NFSU с DXVK/NVK рисует и играется (журнал `console/`).
2. Стенд, режим `software`, 2 запуска из 2: игра работает, DXVK создаёт устройство и swapchain 1280x720, `[NXVK] present N: result 0`, 1400–2000 кадров за ~2 мин. Снимки экрана Eden — сплошной чёрный цвет, нажатие A ничего не меняет.
3. Стенд, режим `wsl` (видеокарта ПК): то же, 2539 кадров, экран чёрный. Значит, дело не в рендерере ПК.
4. В `eden_log.txt` обоих режимов сотни строк `Method 0xc0 on subchannel 4 with no engine bound, argument 0x685` и методы 0x100–0x107, 0x1c2–0x1c8 на подканале 4. Метод 0xc0 = смещение 0x300; у MAXWELL_DMA_COPY_A это LAUNCH_DMA. Строк о привязке подканала 4 нет.
5. OpenTTD через OpenGL (nouveau nvc0) в том же прогоне рисует нормально и реагирует на кнопки.
6. Ещё в журнале Eden: `texture_cache.h:2309 assert Unregistering unregistered page`, `Unmapped Read64 @ 0x5E1…`.
