# Carafe Lab agent instructions

These instructions apply to the whole repository, including `app/`.

Before making changes, read [docs/development.md](docs/development.md). It defines the crate responsibilities,
third-party patches, container builds, resource limits, diagnostics and repository conventions.

Before changing run behavior or emulator configuration, read [docs/lab.md](docs/lab.md).
Use [docs/cards.md](docs/cards.md) when deciding what a successful game run must demonstrate.

When changing documentation, read [docs/README.md](docs/README.md), including "Keeping it".
Read the relevant decisions and research before changing the behavior they describe.

Keep personal instructions, machine-specific configuration and credentials outside tracked project files.
